# Security Policy

## Reporting

Report vulnerabilities privately to the author, Gavin Blacklock (Epsilon0xCell),
through GitHub private vulnerability reporting on this repository when enabled,
or by contacting the author directly before any public disclosure.

## Scope

This is a defensive research instrument from ShatterPoint Security. It is built
for authorised labs, local fixtures, and reproducible measurement only. Every
payload in this repository uses inert, benign markers. No live target is in
scope for the fixtures shipped here.

## Supported versions

Only the latest v0.1.x line is supported during initial research release.
